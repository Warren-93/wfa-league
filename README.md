# Warriors Football Association (WFA) — Next.js App Router + Tailwind

Mobile-first site for fixtures, results, standings, teams, players — with mock auth and admin actions. WFA branding and a global football pitch background included.

## Setup
```bash
npm install
npm run dev
# if icons missing:
npm install lucide-react
```
Open http://localhost:3000

## Notes
- Data: `/api/services/`
- Pitch background files: `/public/bg/pitch.svg` and `/public/bg/pitch-texture.png`
- To use the photo-like background instead of SVG, swap the CSS url in `app/globals.css`
